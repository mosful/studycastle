📖 名詞小百科

🍰 最簡分數

分子和分母互質（最大公因數為1），無法再約分的分數，叫作最簡分數。

例：60/90 → GCD(60,90)=30 → 60÷30=2，90÷30=3
→ 最簡分數 = 2/3（2和3互質）

✂️ 約分

將分子和分母同除以它們的公因數，使分數變小但大小不變的過程。

做法一：逐步約（每次除以一個公因數）
60/90 → ÷2 → 30/45 → ÷3 → 10/15 → ÷5 → 2/3

做法二：直接用 GCD 一次約分（更快！）
GCD(60,90) = 30，60÷30=2，90÷30=3 → 2/3

➗ 分數除法

分數除法的核心公式：除以一個分數 = 乘以它的倒數

公式：A/B ÷ C/D = A/B × D/C

範例：5 ÷ 3/4 = 5 × 4/3 = 20/3 = 6又2/3
範例：3/8 ÷ 9/16 = 3/8 × 16/9 = (3×16)/(8×9) = 48/72 = 2/3

🔄 倒數

把一個分數的分子和分母對調，所得的分數就是原分數的倒數。兩個互為倒數的數相乘等於1。

3/4 的倒數 = 4/3（因為 3/4 × 4/3 = 12/12 = 1）
2又1/3 = 7/3，倒數 = 3/7
整數 5 的倒數 = 1/5

🎂 帶分數

由整數部分和真分數合在一起的分數，例如 2又3/4。在做除法前，通常先把帶分數化成假分數。

2又3/4 = (2×4+3)/4 = 11/4
3又1/5 = (3×5+1)/5 = 16/5

⚖️ 商與被除數比較

在分數除法中（被除數≠0）：

除數 < 1 → 商 > 被除數（例：6 ÷ 1/2 = 12 > 6）
除數 = 1 → 商 = 被除數
除數 > 1 → 商 < 被除數（例：6 ÷ 3/2 = 4 < 6）
